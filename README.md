# Odin Recipes

Basic recipe website built for The Odin Project Foundations “Project: Recipes.”

## Project goals

- Practice HTML boilerplate, headings, links, lists, images, and basic page structure.
- Build a main index page that links to individual recipe pages.
- Create multiple recipe pages with consistent structure.

## What I’m building

- An index page with a list of recipe links.
- Three recipe pages, each including:
	- A dish image
	- Description section
	- Ingredients list
	- Step-by-step instructions
	- A link back to the home page

## Skills demonstrated

- Writing semantic HTML
- Using relative links between pages
- Organizing files and folders in a small static site
- Committing and publishing a simple project
